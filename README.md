# Vehicle Parking Management System

## Feature Set IV

This project is a **Vehicle Parking Management System** designed as a BCA First-Year assignment. It manages vehicle details, parking slots, vehicle entry and exit, parking duration, and parking history.

## Features

- Vehicle Details
- Parking Slot
- Vehicle Entry / Exit
- Parking Duration
- Parking History
